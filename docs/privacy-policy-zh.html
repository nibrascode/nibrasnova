新功能与数据处理

清真搜索模式：搜索结果和网页上的图片由设备端模型（Yahoo open_nsfw，BSD 许可；TensorFlow Lite，Apache-2.0 许可）进行检查，未被判定为安全的图片会被模糊处理；图片绝不会被上传，“点按显示”可由家长 PIN 码保护。礼拜提醒：在每个礼拜时间开始前 10 分钟及开始时（可按每次礼拜分别设置）发出通知，按所选城市的时区在设备上计算。家庭档案：“成人”和“儿童”档案拥有各自独立的历史记录、书签、标签页和 Cookie；“儿童”档案只能打开家长批准的网站（默认为 nibrascode.com 和古兰经网站），切换回来需要 PIN 码。HTML 练习场：带实时预览、控制台、模板、已保存片段和 .html 导出功能的 HTML/CSS/JS 编辑器。上述所有数据均保留在设备上。

朝向（Qibla）界面：带磁偏角校正的指南针及到天房（克尔白）的距离；如果设备没有指南针传感器，则仅显示方位角。城市名称支持 5 种语言（例如 Bakı、Gəncə、Məkkə；数据来自 GeoNames alternateNames，CC BY 4.0），并支持忽略重音符号的搜索。家长控制：4–6 位 PIN 码（使用 PBKDF2 加盐哈希，仅保存在设备上），用于更改设置、清除历史记录或执行紧急清除，另外还可设置额外的屏蔽网站和每日使用时长限制。连续输错 5 次后会临时锁定。如果忘记 PIN 码，唯一的恢复方式是重置应用数据；不使用任何外部服务。用于朝向功能的位置和传感器数据绝不会离开设备。

礼拜时间默认使用乌姆古拉（麦加）计算方法，可在“设置”中更改。城市选择：先选国家，再选城市（离线数据，GeoNames，CC BY 4.0）；时间按该城市的时区显示。

礼拜时间：主页上的礼拜时间在您的设备上计算（adhan 库，无需联网）。如果您授予权限，仅使用大致（粗略）位置；坐标会被舍入到约 1 公里，仅保存在设备上，绝不会发送到任何地方。您也可以选择城市而不共享位置。

备份：以 JSON 格式导出/导入书签和历史记录时，仅写入或读取您所选择的文件；不会上传任何内容。

家庭安全：成人（18+）网站始终被屏蔽，并在 Google、Bing、DuckDuckGo 和 YouTube 上强制启用安全搜索。检查完全在您的设备上使用内置列表（StevenBlack/hosts，MIT 许可）进行；不会发送任何浏览数据。该保护在隐私标签页中同样有效。

1. 概述

Nibras Nova 是由 Nibras Code 开发的网页浏览器。它没有用户账户、没有广告、没有分析工具，也没有崩溃报告 SDK。您在应用中创建的所有内容（历史记录、书签、标签页、设置、笔记、保险箱项目）都只保存在您的设备上。我们作为开发者不会接收或存储您的任何数据。

2. 存储在您设备上的数据

  • 浏览历史、书签、已打开的标签页、快捷链接、下载列表、RSS 订阅源、页面监控、笔记/高亮、用户脚本和设置（保存在本地数据库和应用偏好设置中）。
  • 隐私标签页中的浏览不会写入历史记录。
  • 您创建的保险箱项目和备份使用 AES-256 加密，密钥或密码保留在您的设备上。
  • 应用数据的 Android 云备份已关闭；只有在您自行导出时（书签 HTML 导出、加密备份文件、Wi-Fi 传输），数据才会离开设备。
  • 您可以随时删除所有内容：清除历史记录、使用“紧急清除”或卸载应用。

3. 网络连接

  • 您打开的网站：与任何浏览器一样，您的设备直接连接到这些网站。这些网站有各自的隐私政策。
  • 搜索：您在地址栏中输入的内容会发送到您所选择的搜索引擎（默认 DuckDuckGo；也可选择 Google、Bing、Brave、Startpage 或自定义搜索引擎）。
  • 安全 DNS（可选）：如果您开启 DNS-over-HTTPS，域名查询将发送到您选择的提供商（Cloudflare、Quad9 或 AdGuard）。如果您设置了代理，您的流量将经过该代理。
  • 网页翻译：“翻译页面”会通过 Google 翻译（translate.google.com）打开页面，Google 翻译会收到该页面地址。文本翻译在设备上使用 Google ML Kit 完成；语言模型会从 Google 下载一次，文本本身在设备上翻译。
  • 安全浏览：Android System WebView 可能会将网址与 Google 安全浏览进行比对，以便对危险网站发出警告。
  • RSS 订阅源和页面监控只会访问您添加的地址。
  • Wi-Fi 传输仅在传输界面打开期间在您的本地网络上运行一个临时服务器；不经过互联网。

4. 权限

  • 互联网 / 网络状态：用于加载网页。
  • 相机：仅用于扫描二维码，以及当网站请求使用相机时（会先征求您的同意）。
  • 麦克风：仅在网站请求时使用，例如视频通话（会先征求您的同意）。
  • 位置：仅在网站请求您的位置时使用（会先征求您的同意）。应用本身不收集位置信息。
  • 通知：用于显示下载进度和页面监控提醒。
  • 生物识别：用于解锁私密保险箱和隐私标签页；您的指纹/面部数据绝不会离开 Android 的安全硬件。
  • 存储（仅限旧版 Android）：用于保存下载的文件。
  • Wi-Fi 状态：用于在 Wi-Fi 传输时显示您的本地地址。

5. 共享与出售

我们不出售、出租或共享个人数据。我们不会将您的数据用于广告。

6. 儿童

本应用是一款通用浏览器，并非面向 13 岁以下的儿童。它不会有意收集任何人的任何数据。
